## ¿Qué es Software según IEEE?
Es una colección que contiene:  programas, procedimientos, documentación y datos asociados que determinan la operación de un sistema de computación.
## ¿Cuál es el Dominio del Problema de la IS?
El SOFTWARE INDUSTRIAL: Software de alta CALIDAD* del cuál dependen grandes sistemas o negocios, cuya falla puede ocasionar pérdidas económicas (por la alta inversión al mismo) o muertes.
**Características:** 
* Rigurosamente Testeado, Documentado con respectivo mantenimiento una vez entregado.
* Grande, complejo y elaborado mediante FASES DE DESARROLLO*.
* Proceso de desarrollo COSTOSO respecto al Hardware.

## Diferencias entre Software de Alumno vs Software Industrial

| ALUMNO                                                   |                                           INDUSTRIA |
| :------------------------------------------------------- | --------------------------------------------------: |
| Usuario es el Alumno                                     |                                   Usuario son otros |
| Bugs Tolerables                                          |                              Sin Tolerancia de Bugs |
| UI no importante                                         |                                       UI importante |
| Documentación irrelevante                                | Mucha Docuementacion para el usuario y organización |
| Sin uso Crítico                                          |                                         Uso Crítico |
| Confiabilidad, Robustez, Portabilidad no son importantes |   Confiabilidad, Robustez, Portabilidad importantes |
| No hay inversión                                         |                                    Fuerte inversión |
**DIFERENCIA CLAVE:** CALIDAD*

## ¿Qué significa que los proyectos de Software se categoricen como DESBOCADOS?

Tienen presupuesto y costo fuera de control.

## Diferencia entre Falla Mecánica vs Falla por Software
| FALLA MECÁNICA            |                                                              FALLA SOFTWARE |
| :------------------------ | --------------------------------------------------------------------------: |
| Consecuencia por uso      |               Consecuencia de bugs durante el desarrollo (no por deterioro) |
| Puede darse con el tiempo | Generalmente existe desde el comienzo pero se puede manifestar mas adelante |

## ¿Por qué es necesario el mantenimiento del Software?
Dependerá el enfoque que queramos darle.

**Mantenimiento Correctivo:**
* Corrige errores residuales (updates).
**Mantenimiento Adaptativo:**
* Mejora el funcionamiento del Software (upgrade) y adaptarlo al entorno.
* Incluye comprender:
	* Software existente (código y docs).
	* Efectos de los cambios.
	* Realización de los cambios (código y docs).
	* Testear lo nuevo y Re-Testear lo viejo.

Puede ser más costoso mantener el software que el desarrollo inicial
