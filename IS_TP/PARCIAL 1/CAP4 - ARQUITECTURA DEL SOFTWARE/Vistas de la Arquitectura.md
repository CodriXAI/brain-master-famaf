*No hay una única arquitectura de un sistema*.

## ¿Qué es una vista de la arquitectura?
* Una colección de elementos del software y sus relaciones entre ellos
* Define una estructura.
## ¿Qué tipos hay? Explicar

*OBS: Todas las vistas coexisten entre sí, representando a la misma arquitectura.*
### Módulos:
* Colección de unidades de código.
* Cada una implementa una funcionalidad del sistema.
* El elemento principal son los módulos.
### Componentes y Conectores (C&C):
* *Componentes:* Unidades de ejecución.
* *Conectores:* La relación/interacción entre componentes.
### Asignación de Recursos:
* Cómo las distintas unidades del sistema se asignan a recursos (*HW* por ejemplo).
* Especifica relaciones entre elementos del SW y elementos del entorno.

## ¿Qué es una Descripción Arquitectónica?
* Son un grupo de vistas de distintos tipos, cada una muestra una estructura diferente.
