## Pasos Principales
### Dibujar el diagrama de contexto
* Ve al sistema completo como un transformador e identifica el contexto
* Es un DFD con un único transformador con entradas salidas, fuentes y sumideros del sistema identificado.
### Dibujar el DFD del sistema existente
* El sistema se modela tal como es con un DFD con el fin de comprender su funcionamiento.
* Se refina el diagrama de contexto.
* Cada burbuja es una transformación lógica.
* Se debe interactuar intensamente con el usuario para obtenerlo.
* Se valida junto con el usuario.
### Dibujar el DFD del sistema propuesto e identificar la frontera hombre - máquina
* Utilizar conocimiento/comprensión existente.
* Validar tambien con el usuario.
* *Frontera humano / máquina:* Qué se automatiza y qué será manual.
* Mostrar la interacción entre ambas fronteras.
